# EchoFluent pixel presentation plan

Goal: convert the existing React/Tailwind UI to crisp pixel geometry in both themes, without changing learning, audio, timing, persistence, authentication, data or dependency contracts.

Architecture: keep shared Tailwind aliases and CSS component classes; preserve all existing component props. Use one global Lucide treatment, solid backgrounds, hard shadows and discrete display geometry. Keep native Vietnamese typography readable.

Baseline: branch main; 7 blur/backdrop lines and 10 gradient lines. Existing README.md, IMAGE_PROMPTS.md and src/data edits belong to the user. Their hashes, all prohibited paths, package manifests and existing images are recorded in /tmp/echofluent-pixel-baseline.json.

## Decisions and checks

- Layout spacing: multiples of 4 CSS pixels; existing fractional aliases round upward. Borders: 2px solid. All named radius tokens: zero. Small text, border strokes and fluid layout are exceptions to the spacing grid.
- Shadows: opaque 4px/8px offsets with zero blur. No haze, noise textures, soft gradients or fractional scaling.
- Keep the 12 existing --c-* names. Collapse raised into surface, faint into muted, violet into sky: 9 unique colors per theme. Legacy translucent accent panels map to opaque surface, retaining their accent text and borders.
- Plus Jakarta Sans retains Vietnamese and learning text. Its official TTF cmap contains ế ộ ữ ằ ợ ẩ ẫ. Press Start 2P lacks all seven and is restricted to ASCII branding and digits at 16/24/32px. Do not disable text antialiasing; do not restrict browser zoom.
- Keep lucide-react (option a): centralized 16/24/32px size mapping, thicker square-ended strokes, crispEdges. This is a rendering hint, not hand-drawn pixel geometry; existing curved paths remain recognizable.
- Discrete steps() animation; instant interactive states; keep reduced-motion suppression. Countdown and microphone sample their existing inputs; only display geometry is quantized.
- Keep the existing manga images and asset() calls; remove soft overlays and add opaque frames. No replacement image generation or deletion.

## Execution order

1. tailwind.config.js: geometry, palette aliases, spacing, animation. Validate configuration with the existing Vite build tool. Commit this foundation and plan.
2. src/index.css and index.html: both RGB palettes, font loading, shared card/button/chip/input/label styles, focus and Lucide rules. Inspect rendered components before proceeding. Commit.
3. src/components/ui/primitives.tsx: discrete progress cells, readable Stat and SectionHeader, square toggle/segmented control. Keep existing signatures. Commit.
4. src/components/layout/Shell.tsx: solid desktop/sidebar/mobile navigation, full Vietnamese labels, touch sizes, safe-area spacing. Keep routing/store logic. Commit.
5. Remove hard-coded soft effects in Dashboard, Scenarios, Shadowing, ScenarioPlayer, Onboarding, AnswerFeedback, NudgeQuiz and AchievementToast. Do not edit src/lib/utils.ts; remove only unused imports/calls of the visual gradient helper. Commit.
6. MicButton.tsx and CountdownRing.tsx: stepped recording silhouette, volume cells based on real input, discrete countdown perimeter with the same seconds/ratio calculation and callbacks. Commit.
7. Inspect every route and remaining explicit styling in the nine main pages, ScenarioPlayer, Onboarding, PinGate and shared/settings components. Change only visual markup/styles when necessary. Commit the verified polish.

## Verification contract

- Run npm run check and retain actual typecheck/test/build output. No package.json or lockfile edits.
- Repeat the exact user grep counts: expected 7 → 0 blur/backdrop and 10 → 0 gradient references in TSX/CSS. Existing unused gradient helper in prohibited src/lib remains untouched.
- Run npm run dev on port 5180. Inspect all nine routes at width 390 in dark and light, plus the desktop sidebar, onboarding, scenario player, recording/countdown states and reduced-motion behavior.
- Check Vietnamese glyphs, wrapping, clipping, horizontal overflow, focus, disabled/pressed button states, and image URLs under /echofluent/.
- Recheck baseline hashes for every protected/user-owned file and examine the staged file list before each commit. Report limitations honestly; no deployment is requested.

## Design limits

Keep three things readable/accurate: learning text and IPA, the audio signal itself, and precise time/score values. Pixel geometry changes their framing, not their data. A complete hand-drawn icon family, coordinated replacement illustrations and physical iOS/Android microphone verification can follow separately.
